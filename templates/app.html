ABOUT SPIDER-SENSE

Spider-Sense is a machine-learning based text analysis system designed to estimate whether a piece of writing resembles human-written or AI-generated text.

01 // PATTERN ANALYSIS

Finds Text Patterns

The system converts text into numerical features using TF-IDF and looks for patterns learned from labeled examples.

02 // MACHINE LEARNING

Neural Network

A PyTorch neural network processes the extracted features and produces an estimated probability for AI-generated writing.

03 // HUMAN FEEDBACK

Learning From Corrections

When a user identifies a wrong prediction, the corrected label can be stored as feedback and used during future model retraining.

HOW IT WORKS

Spider-Sense follows a simple analysis and feedback pipeline.

01 // INPUT

Paste Text

Enter an article, paragraph, message, or other text into the analysis box.

02 // ANALYZE

Detect Patterns

TF-IDF converts the text into features and the trained PyTorch model analyzes those features.

03 // FEEDBACK

Correct the Model

If the result is wrong, provide the correct label. Reviewed examples are collected for model retraining.

BUILT WITH
