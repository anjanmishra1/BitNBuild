WHAT IS SPIDER-SENSE?

Pattern Analysis

Spider-Sense analyzes statistical patterns in text using TF-IDF features and a neural network classifier.

Fast Inference

The trained model processes submitted text through a Flask API and returns a prediction and confidence estimate.

Human Feedback

Users can report incorrect predictions. Corrected examples can be collected and used during future model retraining.

Responsible Detection

The detector provides a probabilistic estimate. It should not be treated as definitive proof of who or what authored a piece of text.

HOW IT WORKS

01 // INPUT

Submit Text

Paste an article, paragraph, post, or message into the analysis terminal.

02 // ANALYZE

Spider-Sense

03 // RESULT

Prediction

The system returns an AI or Human prediction together with a confidence estimate.
